# Varna Local Cup

Статический сайт локального велозаезда в Варне. Первый заезд — **13 сентября 2026**, время пока не задано. Шоссе и МТБ вместе, зачёт отдельно среди мужчин и женщин.

Карта из настоящего GPX, профиль высот, участники, таблица мест и отставаний, просмотр треков результатов. Сервер и база данных не нужны. Vite собирает готовый сайт в `dist/`.

## Локальный запуск

Нужен Node.js **22.12+**.

```bash
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite. После изменения JSON-данных перезапустите `npm run dev`. Изменения интерфейса подхватываются автоматически.

## Где редактировать

| Файл | Данные |
| --- | --- |
| `data/event.json` | Название, дата, время старта, статус и настройки проверки GPS |
| `data/participants.json` | Участники, номера и пол |
| `data/results.json` | Подтверждённые результаты; заполняются командой `approve` |
| `public/route.gpx` | Маршрут |

Пример участника (номер — локальный номер в стартовом списке):

```json
{ "id": "ruslan-shchur", "bib": 1, "name": "Руслан Щур", "gender": "male" }
```

`gender`: `male` / `female`. Тип велосипеда на зачёт не влияет. `startTime`: `"09:00"` либо `null`, время местное (`Europe/Sofia`). Статусы: `upcoming` — до старта, `results` — принимаем результаты, `finished` — заезд завершён. Статус задаёт организатор, он не переключается автоматически.

## После заезда

1. Получите оригинальный FIT участника. Файл можно оставить в Downloads или в игнорируемой папке `activities/`.
2. Импортируйте:

```bash
npm run import:fit -- --rider ruslan-shchur --file /полный/путь/ride.fit
```

3. Откройте `activities/reviews/ruslan-shchur.html` в браузере: там время старта и финиша, сравнение GPX / FIT и замечания. Это локальный черновик, его нет на публичном сайте.
4. Подтвердите результат:

```bash
npm run approve -- --rider ruslan-shchur
```

Если есть замечания, изучите их и добавьте объяснение: `--note "Проверен разрыв GPS на остановке, маршрут пройден полностью"`. Неполный маршрут подтвердить нельзя. Для замены существующего результата или черновика нужен `--replace`.

GPS не определяет официальный момент старта автоматически. Если участник ждал у старта или запись проходила через старт несколько раз, можно указать проверенные отметки:

```bash
npm run import:fit -- --rider ruslan-shchur --file /полный/путь/ride.fit \
  --start 2026-09-13T09:00:00+03:00 --finish 2026-09-13T10:35:20+03:00 --replace
npm run approve -- --rider ruslan-shchur --replace --note "Отметки сверены организатором"
```

Отметки должны соответствовать GPS-точкам в пределах стартовой и финишной зон. Укажите `status: "results"` или `"finished"` в `data/event.json` по состоянию заезда.

5. Проверьте и отправьте:

```bash
npm test
npm run build
git add data
git commit -m "Update race results"
git push
```

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub и добавьте его как `origin` этому проекту. Проект рассчитан на основную ветку `main`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Отправьте исходники в `main`. Workflow `.github/workflows/pages.yml` установит зависимости, выполнит тесты, соберёт `dist/` и опубликует его.
4. Адрес появится в **Actions → Build and deploy Varna Local Cup → deploy** и в Settings → Pages.

Каждый `push` в `main` обновляет сайт. Pull request запускает тесты и сборку без публикации. `base: './'` поддерживает и `username.github.io/repository/`, и корневой домен. Вручную коммитить `dist/` не нужно.

Настройка основана на [официальном workflow GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Что публикуется

В публичную сборку входят маршрут, имена участников, пол, номера и подтверждённые результаты с обрезанным GPS-треком. Исходные FIT, данные датчиков, серийные номера устройства и маршрут до старта / после финиша не включаются. `activities/` и `*.fit` игнорируются Git. Содержимое `public/` публикуется целиком — не кладите туда исходные FIT.

Картографическая подложка загружается с OpenStreetMap; при отсутствии сети контур маршрута и GPX остаются доступны. Шрифты и JavaScript включены в сборку.
