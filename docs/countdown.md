# Overview
Обратный отсчёт до начала сбора под названием соревнования.

## Why / Goals
Участники сразу видят, сколько осталось до встречи.

## Behavior
Дни, часы, минуты и секунды обновляются раз в секунду по текущим часам устройства. После возвращения во вкладку значение пересчитывается. По достижении времени сбора появляется «Сбор уже начался», обновление останавливается. Скринридер объявляет начало сбора, но не каждую секунду.

## Data & Files
`src/lib/countdown.js` вычисляет момент сбора и остаток времени; `src/main.js` отображает таймер; `src/style.css` задаёт адаптивный вид.

## Interfaces (CLI/API)
Новых команд и серверных API нет.

## Configuration
Источник: `date`, `meeting.time` и IANA-зона `timezone` в `data/event.json`. При отсутствии времени сбора таймер не отображается.

## Usage Examples
`2026-09-13`, `10:00`, `Europe/Sofia` соответствуют `2026-09-13T07:00:00Z`, независимо от часового пояса посетителя.

## Testing
`npm test`: летний и зимний сдвиг времени Софии, разбиение на единицы, момент начала и прошедшее время. `npm run build` проверяет сборку.

## Risks / Migration Notes
Точность зависит от часов устройства. Для будущих событий избегайте неоднозначного часа перевода часов; несуществующее местное время скрывает таймер. Миграция данных не требуется.
