# Overview
Сайт доступен на русском и болгарском. Переключатель RU / BG расположен в шапке.

## Why / Goals
Участники могут читать расписание, маршрут, правила, погоду и результаты на выбранном языке и отправлять ссылку на болгарскую версию.

## Behavior
`bg.html` всегда открывает болгарскую версию. Явный `?lang=ru` открывает русскую. Выбор сохраняется в localStorage; при обычном посещении главной страницы применяется сохранённый язык. По умолчанию язык русский. Переключение выполняет переход между страницами и сохраняет текущий якорь раздела. При заблокированном хранилище ссылки продолжают работать.

Переведены интерфейс, таймер, погодные статусы, подписи и всплывающие окна карты, таблица и детали результатов, доступные названия кнопок. Даты и числа форматируются через Intl. Имена участников и произвольные заметки организатора сохраняются в исходном написании. Географические названия на тайлах OpenStreetMap определяются поставщиком карты.

## Data & Files
- `src/locales/bg.json`: болгарские переводы, ключи — исходные русские фразы.
- `src/lib/i18n.js`, `src/language.js`: выбор языка и перевод.
- `index.html`, `bg.html`: две HTML-точки входа с общими данными и кодом.
- `scripts/social-preview.mjs`: отдельные title, description, canonical, hreflang и Open Graph для каждой версии.
- `public/og.png`, `public/og-bg.png`: русская и болгарская обложки.

## Interfaces (CLI/API)
`npm run dev`, `npm run build`, `npm test`. Серверный перевод и дополнительные API не нужны.

## Configuration
Общие данные гонки находятся в `data/`. Добавляйте новые пользовательские фразы через `t()` и перевод в `src/locales/bg.json`. При обновлении даты, времени или дистанции обновляйте обе обложки.

## Usage Examples
- Русский: `https://imfurman.github.io/varna-local-cup/?lang=ru`
- Български: `https://imfurman.github.io/varna-local-cup/bg.html`

## Testing
Проверяется приоритет явного языка над сохранённым, наличие переводов для ключей интерфейса, сохранение имён, метаданные и обложки обеих страниц. Сборка формирует оба HTML-файла с относительными путями к общим ресурсам.

## Risks / Migration Notes
Непереведённые произвольные заметки показываются как введены организатором. Обе версии используют одинаковые маршрут и результаты; пересчёт FIT и миграция данных не требуются. Telegram может кэшировать ранее отправленные превью.
