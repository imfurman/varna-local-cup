# Race finale / 13.09.2026

## Overview

Сайт завершённой Varna Local Cup: официальный протокол, одновременный GPS-повтор, персональные разборы, мультяшные портреты и скачиваемые награды. Русская и болгарская версии.

## Why / Goals

Сохранить историю гонки, сделать данные понятными участникам и дать каждому персональную карточку для друзей. Места назначает организатор; аналитика не подменяет его решение.

## Behavior

Общий порядок: Руслан Щур, Илья Гаркуша, Andrii Silent, Никита Безь, Евгения Шацкая. Женя — первая в женском зачёте по явному решению организатора **на сокращённой дистанции**. Её запись 26,1 км не считается полным финишем, в общей таблице нет фиктивного времени/скорости полного маршрута.

Четыре полных записи проверены через 80 контрольных точек GPX. GPS-время с остановками: 1:54:15, 1:57:08, 1:59:04, 2:36:13. Это время между выбранными стартовой и финишной точками, не результат сертифицированного хронометража. Часы FIT не корректировались.

Повтор использует одну шкалу UTC, отображаемую в Europe/Sofia. Старт записей около 16:20, а не плановые 16:30. Скорости проигрывания 15/60/120/300×, перемотка, события, выбор гонщика, следящая камера, общий обзор. Линии — настоящие записи, серый пунктир — GPX. Портреты стоящих рядом гонщиков расходятся для читаемости с указателями на реальные точки. Пропуски >30 секунд не интерполируются и разрывают след. По окончании записи маркер остаётся на последней точке; у Жени это конец сокращённой записи. При скрытии вкладки проигрывание останавливается.

Никита первым пересёк 30 км в 17:38:29, на 3:34 раньше Руслана по абсолютным FIT-часам. Отрезок 30–35 км — 1:05:36. Длинные пространственные остановки около 31,3 и 32,7 км: ~17:43–17:57 и ~18:02–18:36. Причина (прокол) подтверждена организатором. 41:01 — сумма пауз таймера за весь заезд, **не точная длительность ремонта**. Предполагаемого результата без прокола нет.

Аналитика: последовательные отметки каждые 5 км по ближайшим GPS-точкам в радиусе 120 м; средняя скорость с остановками. Быстрейшее окно примерно 30–50 секунд вместо мгновенного пика. GPS-сегменты свыше 100 км/ч отбрасываются (12 точек Никиты). Дрейф на стоянках всё равно влияет на GPS-длину; средняя для полного маршрута использует GPX 40,273 км. Датчики усредняются по времени доступных точек с ограничением веса интервала 15 сек; показано покрытие. Нет датчика — нет выдуманного значения. Набор рассчитывается для локальной диагностики с пространственным сглаживанием, в UI основной профиль — GPX.

Награда открывается диалогом: абстрактный портрет, персональный титул, место, время/дистанция, конфетти и появление с покачиванием. Медаль имеет гранёный металлический корпус, тёмную эмаль, гравировку, текстильную ленту и отдельную палитру золота/серебра/бронзы/четвёртого места. По нажатию медаль вращается. `prefers-reduced-motion` отключает декоративную анимацию. PNG 1080×1350 рисуется Canvas, с локальными шрифтами. Медаль для экрана и PNG создаёт одна SVG-функция `src/lib/medal.js`; в экспорт портрет встраивается как data URL. Стили наград вынесены в `src/awards.css`. Web Share передаёт готовый файл только после нажатия пользователем; при отсутствии поддержки скачивает PNG. Копирование ссылки открывает награду по hash. Для женской награды явная подпись о сокращённой дистанции и решении организатора включена и в PNG.

## Data & Files

- `data/event.json`: `status: finished`.
- `data/results.json`: только четыре полных утверждённых результата, строгая прежняя проверка сохранена.
- `data/finale.json`: официальный порядок, категории, метрики, контрольные времена, sourceHash, courseHash.
- `public/race-replay.json`: разреженные записи пяти участников, `[UnixSeconds, lat, lon, courseM, gpsM, altitude|null]`.
- `src/finale.js`, `src/finale.css`: протокол, разборы и карта.
- `src/finale-stories.js`: проверенные тексты RU/BG, связанные с данной гонкой.
- `src/lib/replay.js`: чистая логика интерполяции, разрывов и категорий.
- `src/awards.js`: диалог, экспорт PNG, ссылки и системное меню шаринга.
- `public/avatars/*-v2.png`: пять абстрактных портретов (ранние версии сохранены); `public/og-finale.png`: обложка завершённой гонки.
- Исходные FIT, локальный manifest с путями и исходное групповое фото **не публикуются**.
- `scripts/prepare.mjs` не дублирует старые trace в JS при наличии finale; повтор загружается отдельным JSON (~208 KB).

## Interfaces (CLI/API)

```sh
node scripts/build-finale.mjs activities/finale/manifest.json
npm test
npm run build
npm run dev
```

Manifest — массив `{id, file, rank, categoryRank, color, avatar}`. `id` соответствует participants; `file` — локальный исходный FIT; `avatar` — имя PNG без расширения. Пример: `{ "id": "ruslan-shchur", "file": "/local/ruslan.fit", "rank": 1, "categoryRank": 1, "color": "#ed583f", "avatar": "ruslan" }`.

`loadRace` проверяет соответствие finale гонке/маршруту и утверждённым временам. Для новой гонки удалите старый finale перед первоначальным импортом. Пересчёт финала создаёт результаты, метрики и повтор заново; тексты и события нужно перепроверить при замене FIT.

## Configuration

Точность основного зачёта по `event.timing`; дополнительные эвристики заданы в `scripts/finale-analysis.mjs`. Порог прореживания повтора — 8 секунд, перед пропусками сохраняется крайняя точка. События прокола и тексты относятся к 13 сентября 2026, не универсальный детектор поломок.

## Risks / Migration Notes

OpenStreetMap — внешняя подложка; при сетевой ошибке следы остаются доступны. Точный трек между пропущенными точками неизвестен. Стартовые GPS-точки различаются на несколько секунд, поэтому абсолютная разница на отметке и разница итогового времени могут отличаться.

Готовые PNG скачиваются без сервера. Web Share зависит от браузера; на desktop доступен PNG/ссылка. Персональный hash не меняет Open Graph: у ссылки общая обложка гонки, персональный медальон следует отправлять PNG. Telegram может кешировать ранее отправленную ссылку; URL обложки получает хэш содержимого.

Generated assets: встроенный `image_gen`, не CLI. Пути и финальные промпты: [finale-art.md](finale-art.md).
