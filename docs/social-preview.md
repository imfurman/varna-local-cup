# Превью ссылки

## Overview

У ссылки Varna Local Cup есть обложка, название и описание для Telegram и других приложений, поддерживающих Open Graph. Обложка оформлена в чёрно-бело-красном стиле сайта.

## Why / Goals

При отправке ссылки участникам сразу видны название, дата, дистанция, время сбора и ориентировочный старт.

## Behavior

Vite добавляет Open Graph, Twitter Card и canonical непосредственно в HTML при сборке. Telegram не требуется запускать JavaScript сайта. Заголовок и описание собираются из актуальных данных заезда и GPX. URL картинки абсолютный, с версией по хешу содержимого; ширина и высота читаются из PNG.

## Data & Files

- `public/og.png`: обложка для ссылки, включается в публикацию.
- `public/og-bg.png`: болгарская обложка для `bg.html`; расписание и дистанцию обновлять в обеих картинках.
- `scripts/social-preview.mjs`: генерация метаданных.
- `data/event.json` и GPX: источник заголовка, описания и параметров заезда.
- `docs/social-preview-prompt.txt`: запрос, использованный для создания обложки встроенным imagegen.

## Interfaces (CLI/API)

`npm run build` — собрать HTML и опубликовываемые файлы. `npm run dev` — локальный предпросмотр с теми же метаданными. Никаких сообщений в Telegram сайт не отправляет.

## Configuration

Публичный URL задан в `scripts/social-preview.mjs`: `https://imfurman.github.io/varna-local-cup/`. При смене домена обновите его. При изменении даты, названия, расписания или дистанции обновите и текст на обложке: PNG не перерисовывается автоматически. PNG обязателен для сборки и проверяется по сигнатуре.

## Usage Examples

Отправьте ссылку `https://imfurman.github.io/varna-local-cup/` в Telegram с включённым предпросмотром ссылок. Сам Telegram определяет окончательный размер и расположение обложки.

## Testing

Проверить `npm run build`, метаданные в `dist/index.html`, соответствие размеров PNG и доступность публичных HTML / PNG с HTTP 200. Сверить изображение и текст с текущим расписанием.

## Risks / Migration Notes

Telegram может сохранять прежний вариант превью. Обновление сайта не гарантирует немедленное изменение уже отправленных сообщений. Версия URL изображения изменяется при замене картинки. Нельзя проверить вид сообщения на стороне Telegram только проверкой HTML: окончательное отображение зависит от клиента и настроек превью.

Источники: [Open Graph](https://ogp.me/), [превью ссылок Telegram](https://telegram.org/blog/link-preview).

## После завершения гонки

При `event.status: finished` обе языковые страницы используют новую обложку `public/og-finale.png` и описания итогов. Приглашение со временем сбора больше не выводится в метаданных. Hash-ссылки наград используют общую обложку; персональную медаль можно отправить как PNG. Подробнее: [финал гонки](race-finale.md).
