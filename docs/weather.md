# Overview
Фон сайта отражает текущую погоду в Варне. Над названием заезда показаны температура, условия, ветер и время данных по Варне.

## Why / Goals
Сайт меняется вместе с погодой, сохраняя читаемость маршрута и результатов.

## Behavior
Open-Meteo запрашивается при открытии и каждые 15 минут в активной вкладке. Кэш в localStorage уменьшает повторные запросы. Возвращение во вкладку проверяет актуальность; скрытая вкладка не обновляет сеть и приостанавливает анимацию.

Фон поддерживает ясную погоду, переменную облачность, пасмурность, туман, дождь, снег и грозу. `is_day` определяет дневную или ночную палитру. При грозе нет вспышек. Анимацию можно выключить кнопкой; настройка сохраняется. Системное `prefers-reduced-motion` также отключает движение.

При ошибке показаны последние данные с отметкой ошибки, пока их возраст не превышает 30 минут. Более старые, некорректные или отсутствующие данные дают нейтральный фон и сообщение о недоступности. Запрос ограничен 10 секундами, восстановление соединения запускает повторную попытку. Работа остального сайта от погоды не зависит.

## Data & Files
- `src/lib/weather.js`: URL, проверка данных, коды WMO, сетевой запрос.
- `src/weather.js`: фон, обновление, кэш, настройка анимации.
- `src/weather.css`: палитры и лёгкая CSS-анимация.
- `tests/weather.test.js`: условия, день/ночь, просроченные и ошибочные ответы.

## Interfaces (CLI/API)
Публичный `https://api.open-meteo.com/v1/forecast` вызывается браузером без ключа, сервера и запроса геолокации посетителя. Используются `temperature_2m`, `weather_code`, `is_day`, `wind_speed_10m`; температура в °C, ветер в м/с, время Unix UTC.

## Configuration
Координаты Варны `43.20807, 27.92384`, интервалы 15/30 минут и URL заданы в `src/lib/weather.js`. Время отображается в `Europe/Sofia`. Это текущая погода города, независимо от даты соревнования.

## Usage Examples
Код 0 днём — тёплое солнце; тот же код ночью — луна и звёзды. Код 61 ночью — дождь в ночной палитре. Кнопка «Выключить анимацию» оставляет погодную палитру статичной.

## Testing
`npm test`, `npm run build`. В браузере проверить реальный ответ, мобильный вид, кнопку анимации и доступность карты. Юнит-тесты покрывают коды погоды, единицы, старые/отсутствующие данные, HTTP 429 и отсутствие сети.

## Risks / Migration Notes
Данные представляют текущие условия погодной модели Open-Meteo, а не собственные измерения организатора. Доступность зависит от стороннего сервиса и его лимитов. Бесплатный API предназначен для некоммерческого использования. Атрибуция Open-Meteo видна в интерфейсе. Никаких миграций или секретов не требуется.

Источники: [Open-Meteo API и коды WMO](https://open-meteo.com/en/docs), [условия использования](https://open-meteo.com/en/terms).
